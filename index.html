    Automatic intake, explicit controls.

    The new event bridge can accept one selected XProtect camera event and request the existing Hafnia workflow. It defaults to a dry run, limits each armed run, rejects stale events and feedback inputs, and shares the durable duplicate, cooldown and daily-budget checks. It adds no private detector or model.

    Automatic initiation is implemented and tested with synthetic events. Two 120-second live gate observations received no motion input; no automatic request was sent. The filmed end-to-end requests used manual triggers.

    Native review events can automatically open a local operator case. Gate cases receive priority over sidewalk cases; review, follow-up and closure leave an audit trail. Closure requires a note and an explicit footage-review confirmation. This queue does not modify the native alarm state.
